## 🛠 Troubleshooting common issues

If the application fails to send an email, check these common items.

- Connection: Ensure your computer maintains an active internet connection. The application cannot fetch updates offline.
- Email Filters: Check your spam or junk folder. The server might flag the automated summary as a bulk message. Add the sender address to your contacts list to resolve this.
- Updates: Periodically check the repository page for new versions. Older versions might stop working as external websites change their layouts.
